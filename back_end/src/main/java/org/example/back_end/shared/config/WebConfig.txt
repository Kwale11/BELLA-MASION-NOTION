@Configuration 어노테이션 Spring 설정 클래스라는것을 명시

CorsRegistry에는 Cors를 적용할 Url, 허용할 프론트 엔드 주소,
허용할 HTTP주소, 허용할 요청헤더, 브라우저에 노출할 응답헤더 등을 등록가능함

Spring이 Bean을 생성함-무엇을 의미하는가?

@Value 어노테이션은 외부 설정값을 가져오는 어노테이션

registry.addMapping("/api/**")
/api/** 경로에 CORS 정책을 적용함
/** 아래의 모든 경로를 의미함.

    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
                .allowedOrigins(allowedOrigins)
                .allowedMethods("GET", "POST", "OPTIONS")
                .allowedHeaders("Content-Type", "Accept")
                .exposedHeaders("Location")
                .maxAge(3600);
    }
    이 코드는 addCorsMappings 메서드를 메서드 체이닝을 사용해서
    오리진, 메서드, 헤더, 등 허용하는 내용들을 설정해주는 과정임

    Origin은 프로토콜 + 호스트 + 포트 로 이루어짐
    http://localhost:5173
    http://localhost:3000
    https://localhost:5173]

    .maxAge(3600);
    브라우저가 CORS 사전요청의 결과를 캐시할수 있는 시간을 초 단위로 설정함
    3600초 = 60분
