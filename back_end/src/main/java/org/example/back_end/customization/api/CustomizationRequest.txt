CustomizationRequest 커스터마이징 요청으로 클라이언트가 보내야 할 데이터형식
DTO임 그냥

record는 데이터를 담기 위한 클래스 문법임.
각 필드는 private final로 보관하고
생성자, shape(), material() 같은 getter,equals(), hashCode(), toString()
같은 코드들을 자동으로 만들어줌

@NotBlank는 null, 빈 문자열 "", 공백만 있는 문자열 " ", 모두 허용하지 않음

@NotBlank: 값이 반드시 있어야 함
@Pattern: 정규식과 완전히 일치해야 함

[1-9]       → 1~9
[12][0-9]   → 10~29
3[01]       → 30 또는 31
"1", "12", "31"은 통과하지만 "0", "32", "01", "12호"는 실패



//////////////////////record 문법

public class User {
    private final String name;
    private final int age;

    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() {
        return name;
    }

    public int getAge() {
        return age;
    }

    @Override
    public String toString() { ... }

    @Override
    public boolean equals(Object o) { ... }

    @Override
    public int hashCode() { ... }
}


이 코드를 아래처럼 간단히 바꿔줄수있음
public record User(String name, int age) {}

record는 값이 바뀌지 않도록 설계되었음.
구성요소는 자동으로 private final 필드가 되며 setter가 없음
DTO처럼 값을 전달하는 객체를 만들 때 반복 코드를 크게 줄여주는 문법정도로 기억하자
